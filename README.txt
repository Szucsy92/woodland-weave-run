WoodlandWeave – ground and bark texture assets

These files are extracted from the binary asset changes in
woodland-weave-ground-bark-collision.diff.

Keep the directory structure when copying into the repository.
The tree-bark atlas files are included in both app/src/main/assets
and src/main/assets because the patch updates both mirrored locations.

Ground maps: wet-ground.jpg, ground-normal.jpg, ground-rough.jpg
Bark maps: tree-bark-atlas.jpg, tree-bark-normal-atlas.jpg, tree-bark-rough-atlas.jpg
